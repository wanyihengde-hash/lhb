# 龙虎榜 · 加速版

在海外用手机看东方财富龙虎榜总是加载不出来，这个仓库把数据「搬」到一个海外访问很快的地方。

```
东方财富数据接口 ──(GitHub Actions 定时拉取，失败自动重试)──> 仓库 docs/data/*.json
                                                               │
手机浏览器 <──(GitHub Pages 全球 CDN，单页 + 一个 JSON)────────┘
```

- **定时同步**：交易日北京时间 16:17 到 21:07 大约每半小时一次，次日 09:07 再补一次。
- **页面很轻**：一个 HTML，外加当天一个 JSON（gzip 后约 30KB）。原页面要从 30 多个域名加载资源，这里只有一个。
- **离线可看**：Service Worker 缓存看过的数据，没网也能打开上次的内容。
- **直连兜底**：右上角「直连东财」由手机直接调用东财接口拿最新一天的数据，适合本站还没同步时用。
- **历史存档**：每天的数据都提交在 `docs/data/` 里，git 历史就是龙虎榜存档。

## 文件

| 路径 | 作用 |
| --- | --- |
| `scripts/fetch_lhb.py` | 拉数据（只用标准库），`--days N` 回补 N 个交易日 |
| `docs/index.html` | 手机页面（筛选、排序、搜股票/营业部、展开看买卖前五） |
| `docs/sw.js` | 离线缓存 |
| `.github/workflows/update.yml` | 定时任务 + 部署到 Pages |

## 手动操作

- 立刻同步一次：仓库 Actions → 同步龙虎榜 → Run workflow（可填回补天数）。
- 本地跑：`python scripts/fetch_lhb.py --days 5`，然后 `python -m http.server -d docs`。

数据版权归东方财富，本项目仅供个人查看，不构成投资建议。
